# وِرْدي | Wardi Pro — Premium Islamic Personal Companion PWA

> **«أَلَا بِذِكْرِ اللَّهِ تَطْمَئِنُّ الْقُلُوبُ»**  
> رفيقك الإسلامي اليومي: تلاوة القرآن الكريم، التسبيح والأذكار المأثورة، حفظ وتنظيم الأدعية الخاصة، وتتبع وردك اليومي دون أي إعلانات أو تتبع وبخصوصية تامة دون إنترنت (Offline-First).

---

## 🌟 نظرة عامة | Overview

**وِرْدي (Wardi Pro)** هو تطبيق ويب تقدمي (Progressive Web App - PWA) صُمم بعناية ليكون رفيقاً شخصياً للمسلم، يجمع بين البهاء البصري المستوحى من التراث الإسلامي الأصيل وأحدث معايير الأداء والخصوصية:
- **خصوصية مطلقة (Local-First):** تُحفظ كافة بياناتك (أدعيتك الشخصية، سجلات التسبيح، علامات القرآن، الإحصائيات) محلياً داخل متصفحك عبر تقنية `IndexedDB` و `LocalStorage`. لا توجد خوادم خارجية، ولا تتبع، ولا حسابات أو كلمات مرور.
- **يعمل دون اتصال (Offline-Ready):** بفضل الـ Service Worker وقواعد البيانات المحلية، يعمل التطبيق بسلاسة كاملة حتى في وضع الطيران ودون شبكة إنترنت.
- **دقة دينية متناهية:** نصوص شرعية موثقة من مصادر موثوقة، وأذكار مأثورة بأسانيدها، وعدم توليد أي آيات أو أحاديث أو أدعية بالذكاء الاصطناعي.
- **تصميم إسلامي راقٍ:** ألوان الزمرد العميق (`#063B32`, `#082C27`)، والأخضر الملكي (`#0D5B48`)، ولمسات الذهب الدافئ (`#D6B46A`) مع خطوط عربية أصيلة (Amiri و Noto Sans Arabic).

## 📱 المميزات المكتملة | Features

### 1. الرئيسية — Dashboard
- تحية متغيرة بحسب أوقات اليوم (الصباح، العصر، المساء).
- عرض التاريخ الهجري المعتمد والتاريخ الميلادي بدقة.
- بطاقة التقدم اليومي للتسبيح ومؤشر الإنجاز مقارنة بالهدف اليومي.
- عداد صفحات القرآن المقروءة اليوم.
- زر «متابعة القراءة» لاستئناف التلاوة فوراً من آخر سورة وآية توقفت عندها.
- قائمة الوصول السريع للأدعية المفضلة.
- شريط النشاط الأخير وسجل العبادات المنجزة.
- تذكير إسلامي متجدد وموثق يومياً.

### 2. القرآن الكريم — Quran Reader
- فهرس كامل للسور الـ 114 بالاسم العربي والترجمة وعدد الآيات ونوع التنزيل (مكية/مدنية).
- محرك بحث فوري وسريع عن السور بالاسم أو الرقم.
- قراءة بنمط المصحف الشريف (Mushaf-style) مع إطارات مزخرفة وفواصل الآيات المرقمة ﴿١﴾.
- بسملة تلقائية مع مراعاة الضوابط الفقهية (عدم عرضها في سورة التوبة، واعتبارها آية أولى في الفاتحة).
- خاصية البحث النصي داخل آيات السورة الحالية مع تمييز فوري للمواضع.
- نظام العلامات المرجعية (Bookmarks): حفظ الآيات والانتقال المباشر إليها بضغطة زر.
- التحكم الكامل في حجم خط المصحف (تكبير وتصغير فوري).
- تنقل مرن بين السور (السابقة / التالية).
- إضافة السور إلى المفضلة للوصول السريع.
- ذاكرة تلقائية لآخر موضع قراءة (Surah + Ayah Position).
- تخزين مؤقت للقرآن في `IndexedDB` للقراءة في وضع عدم الاتصال بالإنترنت، مع توفير نصوص أصيلة مدمجة للقصار (الفاتحة، الإخلاص، الفلق، الناس) للعمل الفوري.

### 3. التسبيح والأذكار — Digital Tasbeeh & Azkar
- عداد تسبيح إلكتروني ذو واجهة لمسية متفاعلة مع حلقة تقدم دائرية بصرية.
- إمكانية زيادة العد (Increment)، والتراجع عن آخر تسبيحة (Undo)، وإعادة التعيين مع تأكيد الحفظ (Reset).
- تغذية راجعة صوتية لطيفة (نغمة هادئة مولدة تقنياً عبر Web Audio API دون أي ملفات خارجية) مع خيار الكتم/التفعيل.
- استجابة بالاهتزاز التفاعلي (Haptic Feedback) على الأجهزة المدعومة.
- دعم أزرار لوحة المفاتيح (Space / Enter) للعد المريح على الحواسيب.
- قائمة أذكار شائعة محددة الأهداف (سبحان الله، الحمد لله، الله أكبر، استغفار، صلاة على النبي...).
- إمكانية تخصيص أي ذكر مع تحديد عدد مرات التكرار المستهدفة.
- حفظ تلقائي للجلسات وإحصاءات حية (اليومي والإجمالي مدى الحياة).
- **موسوعة الأذكار المأثورة الموثقة:**
  - أذكار الصباح
  - أذكار المساء
  - أذكار ما بعد الصلاة المفروضة
  - تسبيح عام
  - أدعية الاستغفار وسيد الاستغفار
  - الصلاة على النبي ﷺ
  - خاصية «تسبيح بهذا الذكر» لنقل أي ذكر مباشرة إلى عداد التسبيح التفاعلي بنقرة واحدة!

### 4. الأدعية — Duas & My Personal Supplications
- **أدعيتي الخاصة:** قسم مخصص للمناجاة وحفظ الأدعية الشخصية.
- إدراج وحفظ كافة الأدعية الواردة في سجل المحادثة الأصلي دون نقصان:
  - دعاء تفريج الهم والحزن (الصيغة الأصلية والصيغة المشكّلة المنقحة).
  - دعاء الرزق وسؤال الفضل والرحمة (الصيغة الأصلية والصيغة المكررة ثلاثاً والمنقحة).
  - أدعية البركة وانشراح الصدر ونور القرآن.
- تصنيف الأدعية في 7 أقسام متكاملة:
  - أدعية شخصية
  - أدعية تفريج الهم
  - أدعية الرزق
  - أدعية الاستجابة
  - أدعية القرآن
  - الصلاة على النبي
  - أدعية متنوعة
- وظائف متقدمة لكل دعاء:
  - إضافة دعاء جديد مع تحديد التصنيف والملاحظات والتكرار.
  - تعديل وحذف الأدعية مع رسائل تأكيد.
  - نسخ نص الدعاء إلى الحافظة بنقرة واحدة مع إشعار نجاح.
  - تمييز الأدعية بالمفضلة بنجمة (★).
  - فلترة سريعة بواسطة أشرطة التصنيفات القابلة للتمرير.
  - بحث لحظي في نص وملاحظات الأدعية.
  - زر نقل الدعاء إلى مسبحة الورد للعد والتكرار.

### 5. السجل والإحصاءات — History & Analytics
- مخطط بياني بصري يعكس نشاطك التعبدي عبر فترات: يومي، أسبوعي، شهري.
- تتبع أيام العبادة المتتالية (Streak Tracker).
- إجمالي التسبيحات وصفحات القرآن المسجلة.
- قائمة الأرقام القياسية الشخصية (أعلى تسبيح يومي، أكثر صفحات قرآن، أطول سلسلة).
- سجل مفصل بالأنشطة والتسبيحات مع التوقيت النسبي (منذ كذا دقيقة/ساعة/يوم).

### 6. الإعدادات والنسخ الاحتياطي — Settings & Data Control
- التبديل الفوري بين الوضع الداكن (الافتراضي الفاخر) والوضع الفاتح (Light Mode).
- دعم كامل للغتين: العربية (RTL) والإنجليزية (LTR).
- شريط تحكم ديناميكي بحجم خط التطبيق العام.
- تفعيل/تعطيل المؤثرات الصوتية والاهتزاز اللمسي.
- تعديل الهدف اليومي للتسبيح.
- **النسخ الاحتياطي والاستعادة (Backup & Restore):**
  - تصدير كامل البيانات وقواعد بيانات التطبيق إلى ملف `JSON`.
  - استيراد واسترجاع البيانات مع فحص صحة الملف والتأكيد قبل الكتابة.
  - خيار مسح شامل للبيانات مع تأكيد مزدوج للأمان.

### 7. تطبيق الويب التقدمي (PWA)
- ملف `manifest.json` مخصص مع أسماء وهوية وألوان التطبيق.
- أيقونات تطبيق عالية الدقة بأحجام 192x192 و 512x512 بخلفية زمردية وهلال ونجمة ذهبية.
- `service-worker.js` لتخزين هيكل التطبيق والخطوط والقرآن دون اتصال.
- قابل للتثبيت كأي تطبيق أصلي على أندرويد (Chrome) وويندوز/ماك (Edge/Chrome) و iOS (Safari).

## 🚀 خطوات النشر على GitHub Pages | Deployment Steps

التطبيق مصمم بمسارات نسبية كاملة (`./`) دون أي اعتماد على خوادم أو مسارات جذرية مطلقة، مما يجعله جاهزاً 100% للنشر الفوري على **GitHub Pages**:

### الخطوة 1: تهيئة المستودع (Git Init)
افتح الطرفية (Terminal / PowerShell) داخل مجلد المشروع:
```bash
cd c:\Users\midoh\OneDrive\Desktop\wardi
git init
git add .
git commit -m "Initial commit: Wardi Pro PWA"
```

### الخطوة 2: الربط بمستودع GitHub
أنشئ مستودعاً جديداً على حسابك في GitHub (مثلاً باسم `wardi-pro`) ثم نفّذ:
```bash
git branch -M main
git remote add origin https://github.com/USERNAME/wardi-pro.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك على GitHub)*

### الخطوة 3: تفعيل GitHub Pages
1. ادخل إلى صفحة المستودع على GitHub.
2. انقر على **Settings** في الشريط العلوي.
3. من القائمة الجانبية اليسرى اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - Source: اختر **Deploy from a branch**.
   - Branch: اختر فرع **main** والمجلد `/ (root)`.
   - انقر على **Save**.
5. انتظر دقيقة واحدة، وسيظهر لك رابط التطبيق الحي المشفر بـ HTTPS:
   `https://USERNAME.github.io/wardi-pro/`

| **العلامات المرجعية للقرآن** | حفظ علامة في سورة وآية معينة ثم القفز إليها | ✅ حفظ واسترجاع دقيق لموضع القراءة |
| **الوضع الداكن والفاتح** | تبديل الثيم من الإعدادات | ✅ تطبيق فوري لمتغيرات الألوان دون وميض |
| **النسخ الاحتياطي والاستعادة** | تصدير بيانات التطبيق إلى ملف JSON ثم استيرادها | ✅ توليد ملف JSON سليم، واستيراده يعيد كافة البيانات بنجاح |

## 🔒 الخصوصية والأمان | Privacy & Security

- **لا خوادم خارجية:** يعمل التطبيق بنسبة 100% داخل جهاز المستخدم.
- **لا جمع للمعلومات:** لا توجد أي مكتبات خارجية لتتبع سلوك المستخدم أو إعلانات أو تحليلات.
- **بياناتك ملكك:** يمكنك تصدير بياناتك أو مسحها نهائياً بضغطة زر واحدة.
